# CKM · consulta dirigida · 13/11/2026

Sustituye la pantalla de 43 campos simultáneos por bloques dirigidos. La entrada inicial contiene seis datos de ámbito/estabilidad. No se exige recorrer todos los bloques; se puede consultar el resultado con información parcial o elegir qué revisar. Los valores de sesión se conservan al cambiar de apartado.

El resultado precede al formulario. Se distinguen estadio para revisión, mínimo documentado y resultado no evaluable. Se muestran dos comprobaciones pendientes y el resto queda disponible como información ampliada. No se interpreta dato ausente como negativo ni se autoriza el uso asistencial.

La fecha cardiovascular aparece cuando se confirma enfermedad clínica o IC. PREVENT y evidencia subclínica solicitan sus datos de procedencia solo si se declaran presentes. Una evidencia de nivel 4 omite bloques de exclusión de niveles inferiores; el bloque renal permanece accesible para precisar subclasificación. Con nivel mínimo 2/3 no se presentan las preguntas de normalidad propias de niveles inferiores.

No se cambian los criterios de evaluateCkm ni la discrepancia renal pendiente ya documentada. El catálogo completo de datos continúa en el modelo; ya no constituye una lista que el usuario deba completar. Pruebas de navegación comprueban datos compartidos, fechas condicionales, evidencia mínima, invalidación tras editar y retirada de preguntas que no cambian el estadio respaldado. El ejemplo sintético con DM2 y enfermedad cardiovascular alcanza evidencia de nivel 4 sin introducir cintura, TG, glucemia o PREVENT.
