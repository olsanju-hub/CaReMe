# Consulta práctica · 13/11/2026

Problema observado por el usuario: demasiada captura antes de encontrar el resultado y falta de acceso evidente al tratamiento.

Se mantiene el contenido de la ficha y todos los bloqueos del motor. La consulta rápida de obesidad muestra seis entradas iniciales; la hepática cuatro. Seguridad y contexto se despliegan aparte; elastografía conserva su apartado opcional. Las consultas detalladas de DM2, IC, ERC e insulina agrupan la ampliación después de la entrada rápida.

El botón superior «Ver orientación y tratamiento» permite consultar el resultado con información parcial. El resumen completo de captura queda plegado para no desplazar la orientación tras una lista de datos ausentes. Los datos no registrados siguen siendo desconocidos y no se convierten en negativos.

Las fichas farmacológicas existentes tienen acceso directo por indicación, con dosis documentales antes de la lista de datos necesarios para aplicarlas. No se añaden productos, dosis ni nuevas recomendaciones. El catálogo es parcial: faltan, entre otros, pautas individualizadas de insulina y tratamiento completo de HTA/dislipemia. Mostrar una ficha no constituye selección de tratamiento ni autorización para su uso.

Pruebas: suite Node y navegación Chromium/WebKit en Actions; escenario nuevo de carga visible, resultado sin ficha completa y acceso a tirzepatida sin declaración de elegibilidad. GitHub Pages publica la rama de revisión.
